# Моды для ShootIn

Готовые к публикации моды для игры **ShootIn** (22 мода). Автор в `mod.json` каждого мода: **ShootIn** — поменяй перед публикацией (см. «Пересборка»).

В папке:

| Папка | Что там |
|---|---|
| `dist/` | **готовые `.zip`-архивы — их и публикуй** (`<id>-1.0.0.zip`) |
| `covers/` | обложки 630×500 для страниц публикации (`<id>.png`) |
| `screenshots/` | кадры из игры для галереи |
| `mods/` | исходные папки модов (то, что внутри архивов) |
| `src/` | исходники скриптов для скриптовых модов |
| `tools/` | сборка, проверка и упаковка (Node.js + Godot) |

## Список модов

### Паки уровней (без кода и без графики — используют врагов и боссов самой игры)

| Мод | Что делает | Уровней |
|---|---|---|
| **Башни** (`tower_climb`) | Четыре высокие башни: карабкайся по платформам вверх, пока враги ждут на каждом ярусе. Наверху — выход, а в последней башне ещё и Око бездны. | 4 |
| **Босс-раш** (`boss_rush`) | Все восемь боссов ShootIn подряд — без беготни по уровням, только бои. В финале сразу трое. | 9 |
| **Зомби-апокалипсис** (`zombie_apocalypse`) | Шесть уровней, кишащих мертвецами: обычные зомби, могильные (встают из земли), рыцари-мертвецы и в конце — Король зомби. | 6 |
| **Небесные острова** (`sky_islands`) | Пять уровней над пропастью: острова разной высоты, ямы по три клетки и летучие мыши. Одно неверное движение — и вниз. | 5 |
| **Полигон** (`training_grounds`) | Учебка для новичков: двенадцать коротких уровней, в каждом — один вид врага или ловушек и подсказка в названии, как с ним справиться. | 12 |
| **Храм ловушек** (`trap_temple`) | Шесть уровней-испытаний: пилы, огненные плиты, шипастые шары, шипы и ямы. Врагов почти нет — только твоя ловкость и тайминг. | 6 |

| Мод | Что делает | Уровней |
|---|---|---|
| **Гробница фараона** (`desert_tomb`) | Пески, мумии, стаи скарабеев, песчаные шаманы, золотые стражи гробницы — и Фараон, который зовёт мумий и бьёт ударной волной. Четыре уровня. | 4 |
| **Лагерь гоблинов** (`goblin_warcamp`) | Красные громилы, сапёры с бомбами, шаманы со спорами и вождь Гракс, который швыряет бомбы дугой и зовёт гоблинов. Четыре уровня. | 4 |
| **Ледяная цитадель** (`frost_citadel`) | Ледяные гули, ползуны из-под снега, ледяные маги — и Ледяной лорд, который бьёт ударной волной, зовёт гулей и бросается тараном. Четыре уровня. | 4 |
| **Преисподняя** (`inferno_pack`) | Огненные скелеты, бесы с огненными шарами, лавовые воины, пепельные мертвецы из праха — и босс «Владыка пламени» с огненным дождём. Четыре уровня. | 4 |
| **Царство теней** (`shadow_realm`) | Фиолетовый мрак: теневые рыцари, призрачные маги, тени, встающие из темноты, — и Теневой властелин с огненными… то есть теневыми шарами. Четыре уровня. | 4 |

### Скриптовые моды (меняют правила игры; содержат код GDScript)

| Мод | Что делает | Уровней |
|---|---|---|
| **Берсерк** (`berserk`) | Убивай врагов подряд: каждое убийство в течение 4 секунд усиливает урон и скорость, до ×2 урона и +30% к бегу. | — |
| **Двойной прыжок** (`double_jump`) | Нажми Space ещё раз в воздухе — и прыгни второй раз. | — |
| **Жажда крови** (`vampire_rage`) | За каждого убитого врага игрок лечится, за босса — сразу на 25. Счёт убийств сохраняется между запусками. | — |
| **Лунная гравитация** (`moon_gravity`) | Прыгаешь в 2,2 раза выше и долго парим в воздухе — как на Луне. | — |
| **Полоски здоровья и урон** (`hud_plus`) | Над раненым врагом появляется полоска здоровья, при каждом попадании всплывает число урона, а в углу — счётчик убийств. | — |
| **Режим хаоса** (`chaos_mode`) | Каждые 25 секунд случается что-то странное: лунные прыжки, тяжёлые ноги, удвоенный урон, нашествие врагов или яблочный дождь. | — |
| **Спидран-таймер** (`speedrun_timer`) | Таймер прохождения уровня в углу экрана и сохранение рекордов по каждому уровню и сложности. | — |
| **Финальный удар** (`boss_slowmo`) | Когда побеждён босс, время на полторы секунды замедляется — как в кино. | — |
| **Хардкор** (`hardcore`) | Враги крепче на 50%, их удары больнее на 50%, у тебя 70 здоровья и половина щита. Для тех, кому «Сложная» кажется лёгкой. | — |
| **Хардкорный режим** (`hardcore_mode`) | Сложность без права на ошибку: умер — начинаешь игру с первого уровня (или выходишь). В настройках: убить всех врагов в финале и «ультра-хардкор» — любой урон убивает. | — |
| **Яблоки с врагов** (`apple_drops`) | С убитых врагов с шансом 30% выпадает яблоко-аптечка, с боссов — два яблока. | — |

> Моды с настройками (**Хардкорный режим**) используют API модов 2 и требуют игру **ShootIn 1.1.0** и новее; остальные работают и в версии 1.0.0.

## Как установить мод игроку

1. Запусти ShootIn → **Моды** → **Установить из файла…** → выбери `.zip` (или вставь ссылку и нажми **Скачать и установить**).
2. Поставь галочку у мода. Скриптовые моды покажут предупреждение — их код открытый, его можно прочитать (`scripts/main.gd` внутри архива).
3. Паки уровней и паки врагов запускаются кнопкой **Играть**; скриптовые работают в любой игре (и в основной кампании, и в кампаниях других модов).

Архив распаковывать не нужно: игра читает `.zip` сама. Несколько модов можно включать одновременно — например «Хардкор» + «Берсерк» + «Полоски здоровья и урон».

## Идеи сочетаний

- **Для новичков:** «Полигон» + «Полоски здоровья и урон» + «Яблоки с врагов».
- **Для профи:** «Хардкорный режим» + «Хардкор» + «Жажда крови» + «Спидран-таймер» + «Босс-раш».
- **Без права на ошибку:** «Хардкорный режим» (в его настройках — убить всех врагов в финале и «ультра-хардкор»: любой урон убивает).
- **Для веселья:** «Режим хаоса» + «Лунная гравитация» + «Двойной прыжок» + «Небесные острова».
- **Кино:** «Финальный удар» + «Босс-раш».

## Публикация

1. Проверь автора и лицензию (ниже).
2. Для каждого мода загрузи `dist/<id>-<версия>.zip`, обложку из `covers/` и описание из `mods/<id>/README.md` (там уже готовый текст на русском: что внутри, как установить).
3. Добавь 1–3 кадра из `screenshots/`.
4. Если что-то поменял — пересобери (раздел ниже) и перепакуй: версия берётся из `tools/config.js`.

## Лицензия и авторы графики

Карты, скрипты и описания модов — авторские (лицензию выбирает публикующий). Графика паков врагов — **перекрашенные спрайты наборов LuizMelo (CC0)**: Monsters Creatures Fantasy, Monsters Creatures Fantasy 2, Medieval King Pack 2, Hero Knight, Evil Wizard 2 — https://luizmelo.itch.io/ . CC0 разрешает использование и изменение без обязательной атрибуции, но упомянуть автора приятно; это уже есть в README каждого мода. Паки уровней и скриптовые моды своей графики не содержат.

## Пересборка и проверка

Нужны Node.js и Godot 4.3 (путь к нему — переменная `GODOT`, по умолчанию Desktop), игра лежит в `D:/shootin`.

```
node tools/build.js                   # собрать все моды (карты проверяет валидатор игры)
node tools/build.js --author "Имя"     # то же, с другим автором в mod.json
node tools/build.js trap_temple        # собрать один мод
godot --headless --path D:/shootin --script D:/ShotMOD/tools/pack.gd          # упаковать в dist/*.zip
godot --headless --path D:/shootin --script D:/ShotMOD/tools/check_dist.gd    # поставить архивы как игрок и загрузить все уровни
godot --headless --path D:/shootin --script D:/ShotMOD/tools/test_script_mods.gd   # проверить поведение скриптовых модов
godot --headless --path D:/shootin --script D:/ShotMOD/tools/test_hardcore_mode.gd  # проверить «Хардкорный режим»: настройки, смерть, ультра, финал
godot --path D:/shootin --resolution 1280x720 --script D:/ShotMOD/tools/make_hardcore_shots.gd   # кадры для публикации (нужно окно)
```

Скрипты скриптовых модов лежат в `src/<id>/scripts/main.gd` — правь их и пересобирай.
