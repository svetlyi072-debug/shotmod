# Хардкорный режим

**Мод для ShootIn** · версия 1.0.0 · автор ShootIn

Сложность без права на ошибку: умер — начинаешь игру с первого уровня (или выходишь). В настройках: убить всех врагов в финале и «ультра-хардкор» — любой урон убивает.

Мод со скриптами: код — обычный текст в `scripts/main.gd` (его можно прочитать и поменять).

## Что внутри

- сложность забега задаёт мод: по умолчанию «Сложная» (умные враги, щита нет); можно выбрать «Нормальную», «Лёгкую» или «как в меню»
- смерть — конец забега: после неё только «начать игру с 1 уровня» или выход в меню; «Продолжить» стирается, перезапуск уровня клавишей R и из паузы отключён
- настройка «В финале убить всех врагов»: на последнем уровне мало победить главного босса (в основной игре — Древнего слизня), игра закончится только когда не останется ни одного врага; в HUD виден счётчик врагов
- настройка «Ультра-хардкор»: любой полученный урон — сразу смерть, даже один укол шипов

## Как установить

1. Запусти игру → **Моды** → **Установить из файла…** и выбери скачанный `.zip` (или **Скачать и установить**, если у тебя есть ссылка).
2. Поставь галочку у мода и подтверди предупреждение: мод содержит скрипты (их можно прочитать — это обычный текст).

Распаковывать архив не нужно — игра читает его сама.

## Заметки

- Настройки меняются в меню «Моды» → выбрать мод → «Настройки мода»; новые значения действуют со следующего забега.
- Работает и в основной кампании, и в кампаниях других модов (там смерть возвращает на первый уровень этой кампании).
- Требует ShootIn 1.1.0 и новее (API модов 2); в старой игре мод не включится и покажет понятное сообщение.
- Сочетается с модами «Хардкор» (крепче враги, больнее удары), «Жажда крови» и «Спидран-таймер».
- Если включить «В финале убить всех врагов», уровень не закончится, пока жив хоть один враг — в том числе необязательные боссы финала.

## Лицензия и авторы

Код и описание — автор мода. Мод использует только API модов ShootIn (`extends ModScript`).
