# Небесные острова

**Мод для ShootIn** · версия 1.0.0 · автор ShootIn

Пять уровней над пропастью: острова разной высоты, ямы по три клетки и летучие мыши. Одно неверное движение — и вниз.

Платформинг без передышки: между островами — пропасти, перепрыгивай их на разбеге. На длинных островах отдыхают аптечки и редкие враги, в воздухе кружат мыши.

В последнем уровне ждёт Око бездны — победи его, и кампания пройдена.

## Что внутри

- 5 уровней
- ямы по 3 клетки — прыгай с разбега (Shift ускоряет бег)
- летучие мыши и Око бездны

## Как установить

1. Запусти игру → **Моды** → **Установить из файла…** и выбери скачанный `.zip` (или **Скачать и установить**, если у тебя есть ссылка).
2. Поставь галочку у мода.
3. Выбери мод в списке → **Играть** → сложность.

Распаковывать архив не нужно — игра читает его сама.
