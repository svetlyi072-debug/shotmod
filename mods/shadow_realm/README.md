# Царство теней

**Мод для ShootIn** · версия 1.0.0 · автор ShootIn

Фиолетовый мрак: теневые рыцари, призрачные маги, тени, встающие из темноты, — и Теневой властелин с огненными… то есть теневыми шарами. Четыре уровня.

Пак с новой графикой (спрайты игры в фиолетово-чёрной палитре) и боссом, чьи атаки описаны данными. Властелин зовёт теней из-под земли, бьёт волной и рушит на арену дождь зарядов с красными метками.

## Что внутри

- **Теневой рыцарь** (`e`) — тяжёлый воин
- **Призрачный маг** (`v`) — бросает заряды
- **Тень** (`t`) — прячется в земле и встаёт, когда подойдёшь
- **Теневой властелин** (`D`) — босс
- 4 уровня: «Сумеречная дорога», «Склеп теней», «Зал зеркал» (зачистка), «Трон властелина»

## Как установить

1. Запусти игру → **Моды** → **Установить из файла…** и выбери скачанный `.zip` (или **Скачать и установить**, если у тебя есть ссылка).
2. Поставь галочку у мода.
3. Выбери мод в списке → **Играть** → сложность.

Распаковывать архив не нужно — игра читает его сама.
