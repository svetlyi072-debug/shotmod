# Башни

**Мод для ShootIn** · версия 1.0.0 · автор ShootIn

Четыре высокие башни: карабкайся по платформам вверх, пока враги ждут на каждом ярусе. Наверху — выход, а в последней башне ещё и Око бездны.

Вертикальные уровни: платформы чередуются слева и справа через каждые два ряда. Упал — не страшно, внизу сплошной пол, но подниматься придётся заново.

Враги стоят на ярусах, аптечки — через каждые четыре платформы.

## Что внутри

- 4 башни: 12, 16, 20 и 24 яруса
- скелеты, зомби, гоблины, грибники, мыши
- босс — Око бездны

## Как установить

1. Запусти игру → **Моды** → **Установить из файла…** и выбери скачанный `.zip` (или **Скачать и установить**, если у тебя есть ссылка).
2. Поставь галочку у мода.
3. Выбери мод в списке → **Играть** → сложность.

Распаковывать архив не нужно — игра читает его сама.
