# Полигон

**Мод для ShootIn** · версия 1.0.0 · автор ShootIn

Учебка для новичков: двенадцать коротких уровней, в каждом — один вид врага или ловушек и подсказка в названии, как с ним справиться.

Не знаешь, как победить скелета или что делать с катящимся панцирником? Здесь каждый враг получает свой небольшой зал: два-три противника, аптечки и подсказка в названии уровня.

Последний зал — «Экзамен»: все враги вперемешку.

## Что внутри

- 12 коротких уровней
- слизни, мыши, скелеты, гоблины, грибники, крысы, мимики, панцирники, зомби, могильные зомби и рыцари, ловушки
- идеально для первого знакомства с игрой

## Как установить

1. Запусти игру → **Моды** → **Установить из файла…** и выбери скачанный `.zip` (или **Скачать и установить**, если у тебя есть ссылка).
2. Поставь галочку у мода.
3. Выбери мод в списке → **Играть** → сложность.

Распаковывать архив не нужно — игра читает его сама.
