# Босс-раш

**Мод для ShootIn** · версия 1.0.0 · автор ShootIn

Все восемь боссов ShootIn подряд — без беготни по уровням, только бои. В финале сразу трое.

Девять арен, одна за другой. На каждой — один босс и несколько аптечек. Здоровье в начале арены полное, а шкала силы переходит дальше, как в основной игре.

Порядок: Король-гриб → Костяной рыцарь → Око бездны → Огненный червь → Тёмный колдун → Древний слизень → Царь-Панцирь → Король зомби → **«Тройная угроза»** (Костяной рыцарь, Король зомби и Око бездны одновременно).

## Что внутри

- 9 арен
- используются только боссы и ловушки самой игры — мод не добавляет картинок и кода
- Лёгкая / Нормальная / Сложная сложности работают как обычно

## Как установить

1. Запусти игру → **Моды** → **Установить из файла…** и выбери скачанный `.zip` (или **Скачать и установить**, если у тебя есть ссылка).
2. Поставь галочку у мода.
3. Выбери мод в списке → **Играть** → сложность.

Распаковывать архив не нужно — игра читает его сама.

## Заметки

- Умер — арена начинается заново (клавиша R). Прогресс по раундам сохраняется: «Продолжить» вернёт на последний раунд.
