# Хардкор

**Мод для ShootIn** · версия 1.1.0 · автор ShootIn

Сложность без права на ошибку: умер — сохранение стирается, игра начинается с первого уровня (или выходишь). В настройках: убить всех врагов в финале, «ультра-хардкор» (любой урон убивает) и крепкие враги.

Мод со скриптами: код — обычный текст в `scripts/main.gd` (его можно прочитать и поменять).

## Что внутри

- по умолчанию — «Сложная» (умные враги, щита нет) и «одна жизнь»: после смерти только «начать игру с 1 уровня» или выход в меню; кнопка «Продолжить» стирается, перезапуск уровня клавишей R и из паузы отключён
- настройки мода — каждую можно включить или оставить выключенной: сложность (Сложная / Нормальная / Лёгкая / как в меню), «Одна жизнь», «В финале убить всех врагов», «Ультра-хардкор», «Крепкие враги»
- «В финале убить всех врагов»: на последнем уровне мало победить главного босса (в основной игре — Древнего слизня), игра закончится только когда не останется ни одного врага; в HUD виден счётчик врагов
- «Ультра-хардкор»: любой полученный урон — сразу смерть, даже один укол шипов
- «Крепкие враги» (так работал «Хардкор» 1.0): здоровье врагов и боссов ×1,5, удары по игроку на 50% больнее, у игрока 70 здоровья и щит вдвое меньше — по умолчанию выключено

## Как установить

1. Запусти игру → **Моды** → **Установить из файла…** и выбери скачанный `.zip` (или **Скачать и установить**, если у тебя есть ссылка).
2. Поставь галочку у мода и подтверди предупреждение: мод содержит скрипты (их можно прочитать — это обычный текст).

Распаковывать архив не нужно — игра читает его сама.

## Заметки

- Настройки меняются в меню «Моды» → выбрать мод → «Настройки мода»; новые значения действуют со следующего забега.
- Работает и в основной кампании, и в кампаниях других модов (там смерть возвращает на первый уровень этой кампании).
- Версия 1.1.0 требует ShootIn 1.1.0 и новее (API модов 2); в старой игре мод не включится и покажет понятное сообщение. Версия 1.0.0 («Крепкие враги» без настроек) работает в ShootIn 1.0.0.
- Если включить «В финале убить всех врагов», уровень не закончится, пока жив хоть один враг — в том числе необязательные боссы финала.
- Хорошо сочетается с модами «Берсерк», «Жажда крови» и «Спидран-таймер».

## Лицензия и авторы

Код и описание — автор мода. Мод использует только API модов ShootIn (`extends ModScript`).
