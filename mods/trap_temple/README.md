# Храм ловушек

**Мод для ShootIn** · версия 1.0.0 · автор ShootIn

Шесть уровней-испытаний: пилы, огненные плиты, шипастые шары, шипы и ямы. Врагов почти нет — только твоя ловкость и тайминг.

Каждый следующий зал плотнее набит ловушками. Пила ездит по полу, огонь вспыхивает по расписанию, шар качается на цепи — запомни ритм и проходи в паузах.

Ловушки ранят и врагов, так что мыши, залетающие в последних залах, сами иногда попадают под них.

## Что внутри

- 6 уровней нарастающей сложности
- пилы, огненные ловушки, шипастые шары, шипы, ямы, дощечки
- в начале — тренировочные залы, в конце — «Зал смерти»
- аптечки лежат перед самыми опасными участками

## Как установить

1. Запусти игру → **Моды** → **Установить из файла…** и выбери скачанный `.zip` (или **Скачать и установить**, если у тебя есть ссылка).
2. Поставь галочку у мода.
3. Выбери мод в списке → **Играть** → сложность.

Распаковывать архив не нужно — игра читает его сама.
