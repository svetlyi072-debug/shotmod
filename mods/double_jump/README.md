# Двойной прыжок

**Мод для ShootIn** · версия 1.0.0 · автор ShootIn

Нажми Space ещё раз в воздухе — и прыгни второй раз.

Мод со скриптами: код — обычный текст в `scripts/main.gd` (его можно прочитать и поменять).

## Что внутри

- один дополнительный прыжок в воздухе (`AIR_JUMPS`)
- сила второго прыжка — 90% от обычного (`AIR_JUMP_POWER`)
- после приземления прыжок восстанавливается

## Как установить

1. Запусти игру → **Моды** → **Установить из файла…** и выбери скачанный `.zip` (или **Скачать и установить**, если у тебя есть ссылка).
2. Поставь галочку у мода и подтверди предупреждение: мод содержит скрипты (их можно прочитать — это обычный текст).

Распаковывать архив не нужно — игра читает его сама.

## Заметки

- Игровые уровни рассчитаны без двойного прыжка, поэтому с модом многое проходится проще.

## Лицензия и авторы

Код и описание — автор мода. Мод использует только API модов ShootIn (`extends ModScript`).
