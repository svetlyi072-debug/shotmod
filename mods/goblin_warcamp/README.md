# Лагерь гоблинов

**Мод для ShootIn** · версия 1.0.0 · автор ShootIn

Красные громилы, сапёры с бомбами, шаманы со спорами и вождь Гракс, который швыряет бомбы дугой и зовёт гоблинов. Четыре уровня.

Гоблинский пак: враги собраны из спрайтов гоблина игры (громилы — красные, шаманы — ядовито-зелёные). Вождь Гракс в три раза крупнее обычного гоблина и командует всей бандой.

## Что внутри

- **Громила** (`a`) — крупный, крепкий, бьёт тяжело
- **Сапёр** (`u`) — швыряет бомбы по дуге
- **Шаман** (`h`) — кидает ядовитые споры
- **Вождь Гракс** (`X`) — босс: удар, дождь бомб, топот, призыв гоблинов и громил, таран
- 4 уровня: «Частокол», «Лагерь», «Оружейная» (зачистка), «Шатёр вождя»

## Как установить

1. Запусти игру → **Моды** → **Установить из файла…** и выбери скачанный `.zip` (или **Скачать и установить**, если у тебя есть ссылка).
2. Поставь галочку у мода.
3. Выбери мод в списке → **Играть** → сложность.

Распаковывать архив не нужно — игра читает его сама.

## Заметки

- В «Шатре вождя» Гракс зовёт и встроенных гоблинов (`g`), и своих громил (`a`).
