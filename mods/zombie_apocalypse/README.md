# Зомби-апокалипсис

**Мод для ShootIn** · версия 1.0.0 · автор ShootIn

Шесть уровней, кишащих мертвецами: обычные зомби, могильные (встают из земли), рыцари-мертвецы и в конце — Король зомби.

Окраина, кладбище, баррикада, склеп, зал мертвецов — и трон Короля зомби. Могильные зомби лежат в земле, пока не подойдёшь ближе двух клеток; удар по ним тоже будит. Рыцарь-мертвец медленный, но бьёт тяжело.

В закрытых залах («Баррикада», «Зал мертвецов») выход открывается, только когда не останется ни одного врага.

## Что внутри

- 6 уровней
- зомби `z`, могильные `y`, рыцари `x`, немного скелетов
- два закрытых зала на зачистку
- финальный босс — Король зомби

## Как установить

1. Запусти игру → **Моды** → **Установить из файла…** и выбери скачанный `.zip` (или **Скачать и установить**, если у тебя есть ссылка).
2. Поставь галочку у мода.
3. Выбери мод в списке → **Играть** → сложность.

Распаковывать архив не нужно — игра читает его сама.
